# 📊 Dashboard de Vendas - Porsche

Este projeto consiste em um painel interativo de vendas desenvolvido para análise de dados, integrando processamento em Python e visualização web em HTML.

## 🚀 Tecnologias Utilizadas
* **Python**: Processamento e manipulação de dados (`main.py`, `dashboard.py`).
* **HTML5 / CSS3**: Estruturação e estilização do painel interativo.
* **GitHub Pages**: Hospedagem e visualização pública do dashboard.

## 🌐 Acesse o Dashboard Online
Você pode visualizar a aplicação em funcionamento através do link do GitHub Pages:
🔗 [Acesse o Dashboard Aqui](https://aluiz-91.github.io/Dashboard_porsche_sales/)

## 📁 Estrutura do Repositório
* `index.html`: Arquivo principal contendo a interface visual do painel.
* `main.py` / `dashboard.py`: Scripts em Python para tratamento e lógica de dados.
* `porsche_sanitizer.xlsx`: Base de dados tratada utilizada no projeto.
